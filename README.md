# Augen RE

Landing page de **Augen RE** para informar sobre la promoción y permitir a los usuarios localizar ópticas participantes.

## Funcionalidad

- Información de la promoción.
- Geolocalización del usuario.
- Consulta de ópticas cercanas.
- Visualización de ubicaciones en mapa.

## Tecnologías

- HTML / PHP
- CSS
- JavaScript
- jQuery
- Bootstrap
